---
title: "Configuration"
description: "Workspace, models and auxiliary services"
---

Select a bot model from the OpenCode catalog. Configure provider authentication in OpenCode, not in QuatiBot.

`QUATI_DATA_DIR` selects the server workspace. Optional Jev, voice and image credentials are configured in Settings and encrypted in the server vault.

Use the profile menu's **Extensões** panel to inspect global OpenCode MCP servers, plugins and skills. MCP switches affect only QuatiBot sessions, starting with their next message. [Learn about extensions](/docs/providers).

---
title: "First bot"
description: "Create a profile and start a conversation"
---

Create a bot, choose an available OpenCode model and give it instructions. Send a message to start a turn. The conversation shows text, tool activity and permission requests.

Use separate tasks for separate threads. Add bots to a room for shared work; mention a bot to choose its recipient, or use automatic room routing.

Enable the bot's browser when a task needs websites. Choose Local VM only when the container runtime and sandbox image are ready. Terminal commands execute on the backend host.

---
title: "QuatiBot"
description: "A Linux web workspace for AI bots"
---

QuatiBot combines chat, bot profiles, rooms, memory and routines with OpenCode V2 execution.

Start with [installation](/docs/getting-started/installation), configure [OpenCode](/docs/providers), and choose the bot's [browser or isolated VM](/docs/computers).

The Node backend owns workspace state and serves the web interface. OpenCode owns provider authentication and native extensions. [Access and secrets](/docs/security) are enforced on the server.

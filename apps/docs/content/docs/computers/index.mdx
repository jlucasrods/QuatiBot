---
title: "Agent environments"
description: "Own browser and isolated desktop"
---

Bots use a dedicated Chromium profile and an isolated container desktop. These environments are independent of the browser displaying the interface.

- [Browser](/docs/computers/browser): tabs, logins, downloads and screenshots.
- [Local VM](/docs/computers/local-vm): sandbox lifecycle, viewer, files and desktop interaction.

`record_screen` saves browser or VM video as WebM for 1–30 seconds and requires `ffmpeg` on the backend. A live preview and a saved recording are separate features.

Terminal commands run through OpenCode on the backend host. Computer selection does not automatically move a terminal into the VM.

---

Documentation describes supported behavior, ownership boundaries and operational requirements. Commands and links must resolve to the current codebase.

Keep the repository guides and the site navigation aligned. Use isolated fixtures for examples involving writes. Distinguish a fixture protocol check from real model inference, browser execution or VM execution.

Do not include credentials, personal workspace data, historical implementation diaries or speculative feature plans in product guides.

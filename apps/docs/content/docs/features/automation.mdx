---
title: "Routines and automation"
description: "Repeatable work through the backend"
---


Routines give bots repeatable work. A routine defines its instructions, target and trigger. Scheduled routines use the backend's scheduling service; event-triggered work enters the same conversation orchestration as ordinary turns.

The server must be running for schedules and incoming triggers to execute. Closing a browser tab does not stop the backend. Stopping the backend stops its active scheduler; operating-system wake behavior is not part of the web application.

Routine results and failures are visible in the workspace. Approval and tool restrictions still apply to unattended work. Choose an environment that is available on the backend host and avoid instructions that require an unattended person to answer a login or approval prompt.

Webhook receivers should be exposed only through an intentional, narrowly configured HTTPS route. Treat webhook credentials as secrets and keep the main API protected by session authentication.

The Node CLI can submit work, wait for completion and export results. Use `pnpm quati help` and the per-command help output for available arguments.

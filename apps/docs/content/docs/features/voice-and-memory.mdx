---
title: "Voice and memory"
description: "Speech services and durable bot context"
---

Voice uses the browser microphone and the configured speech or live-call services. Microphone access requires a secure browser context, such as HTTPS or localhost, and the person's permission.

Service keys are optional auxiliary credentials stored in the server vault. Select the service and voice settings appropriate for the backend.

Memory stores useful context for later bot work; conversation history records messages and execution activity. Review sensitive facts before exporting or sharing workspace data.

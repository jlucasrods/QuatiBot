---
title: "Troubleshooting"
description: "Check the component that owns the failure"
---

- **Cannot open the interface:** verify the Node server is running and the frontend has been built. The local default is `http://127.0.0.1:8799`.
- **Pairing code refused:** request a fresh code on the server and confirm its destination. Codes expire and work once.
- **No models:** check OpenCode V2 authentication for the same user running the backend, then refresh its model catalog.
- **Extensions list incomplete:** refresh the global inventory. Project definitions and skills without attributable global provenance are not part of that list.
- **Browser unavailable:** inspect `pnpm quati browser status` and the backend's Chromium diagnostics.
- **VM unavailable:** verify the runtime daemon, sandbox image and container readiness. A runtime executable alone is insufficient.
- **Recording failed:** check `ffmpeg`, the selected environment and active turn authority.
- **Vault cannot be decrypted:** restore the matching key and ciphertext. Do not replace an unreadable vault with an empty one.

Inspect the relevant local server logs. Redact keys, tokens, prompts, paths and private page content before sharing diagnostics.
